画布是什么

ZPIKA 无限画布是面向客户的可视化工作台，把本站中转的文字 / 图片 / 视频能力接到同一块画布里使用，而不是只靠命令行 / SDK 调 API。

画布地址：https://canvas.zpika.com/

视频生成

固定「视频」分组，默认模型为 Seedance 2.0 Mini，也可选择其它 Seedance 或 Veo 模型。

图片生成

固定「Gemini画图」与「OpenAI画图」两组，可同时配置，画布内按默认绑定切换。

开通流程

! 新账号需要管理员审核后才能使用 注册完成后请主动联系管理员告知账号信息（邮箱：snamio131@gmail.com）；审核通过前，部分能力可能不可用。
  1. 注册账号 打开 https://canvas.zpika.com/ 完成注册 / 登录。
  2. 通知管理员审核 把注册使用的账号（用户名 / 邮箱等）发给管理员邮箱 snamio131@gmail.com，等待审核通过。
  3. 打开「配置与用户偏好」 审核通过后，选择自定义渠道 / 本地模式。界面已锁定 4 个固定分组，无需再手写 Base URL 或协议。
  4. 按分组填写 Key 并拉取模型 每个分组分别填入中转站对应套餐的 API Key，点「拉取模型」；推荐模型会自动勾选。
  5. 同一画布一起用 文字 / 画图 / 视频分组可同时配好，在同一块画布中切换或组合使用。

如何配置分组

! 不再自由新增任意渠道 最新版本改为锁定 4 个预设分组。每个分组通常对应中转站不同套餐 Key，请分别填写；旧的多渠道自由配置会自动迁移到这 4 组。

审核通过后，进入画布 配置与用户偏好：

  1. 渠道模式选本地 / 自定义（需管理员已开启普通用户自定义渠道权限）。
  2. 在分组下拉里切换：文字 / OpenAI画图 / Gemini画图 / 视频。
  3. 只填该分组的 API Key（协议与直连地址已预设）。
  4. 点击拉取模型：画布会自动使用 [直连域名]。
  5. 若上游有推荐模型，会自动勾选；也可手动增删模型标签。
  6. 在下方「默认生图 / 视频 / 文本 / 音频渠道与模型」确认绑定（显示为「分组名 / 模型名」）。

至少完整配置一个分组（Key + 已选模型）后才能正常使用本地模式。

默认生成参数

配置升级后，画布侧默认值如下（浏览器里残留的旧官方默认会一次性纠正）：

  • 图片：默认 4K + 9:16 + 1 张
  • 视频：默认 Seedance 2.0 Mini + 480p + 5s + 16:9，默认生成声音
  • 默认绑定：生图默认 Gemini画图；视频默认视频分组；文本 / 音频默认文字分组

生成时仍可在节点面板里改分辨率、比例、张数与模型。

画布怎么操作

画布的基本思路是：先把素材放上去，再用连线告诉系统“这个素材要拿来做什么”。图片、视频、文字可以在同一个画布里串起来。

  1. 从电脑直接拖入图片或视频 在文件管理器中选中本地图片或视频，直接拖到浏览器里的画布空白处。松开后会生成对应素材节点，不需要先上传到图床或复制链接。
  2. 从素材节点拉出一根线 把鼠标移到图片、视频或文本节点的连接点，按住并拖到画布空白位置后松开。此时会出现创建菜单。
  3. 选择要生成的内容 在菜单里选择图片生成、视频生成或文本生成。系统会创建新节点，并自动把刚才的素材连到这个任务上。
  4. 写提示词并开始生成 在新节点或生成配置中输入想要的效果，确认模型和参数后开始生成。上游连接的图片/视频会作为参考素材参与本次生成。
  5. 在提示词里用 @ 指名引用素材 在提示词输入框键入 @，会出现当前任务已连接资源的候选项，例如图片1、视频1。点击或用方向键选中后，继续写说明即可，例如“让 @图片1 中的产品在 @视频1 的场景里旋转展示”。
  6. 继续往下连 结果生成后还可以再次拉线。例如先用图片生成概念图，再连到视频生成；或者先生成文字脚本，再接到图片、视频任务中使用。
! 连线的意义是传递参考素材 连接后的图片、视频或文本会成为该任务可用的 @ 候选。建议先把素材整理好，再从需要作为“源头”的节点拉线，后续修改和重试会更清楚。

常用：图片 → 视频

拖入产品图，拉线选择“视频生成”，写运动、镜头和场景描述，即可把图片作为视频参考。

常用：文字 → 图片

先生成或写好文案，再从文本节点拉线选择“图片生成”，让文字内容成为画面的提示词来源。

常用：@图片 / @视频

连接好素材后，在提示词里输入 @ 选中图片或视频，明确告诉模型每个素材在本次生成中要承担什么作用。

画布 + Seedance 视频

  1. 配置视频分组填写本站 API Key，拉取并勾选 Seedance 模型；默认使用 doubao-seedance-2-0-mini-260615。
  2. 连接参考素材把图片、视频或音频拖进画布，从素材节点拉线并选择“视频生成”。
  3. 使用 @ 明确引用在提示词中输入 @，选择后会保留为 @图片1、@视频1、@音频1 标签。
  4. 确认输出参数默认 Mini、480p、5 秒、16:9、有声音；比例选项会显示对应像素尺寸。
  5. 等待回填任务会显示生成进度，完成后经过服务器下载、浏览器下载和本地保存，再自动回填到画布。
! 参考视频会增加实际支付金额参考时长越长、数量越多，用量通常越高；两个参考视频即使总时长相同，也可能比单个参考视频更贵。参考图片的影响通常较小。

Seedance 客户价格总体约为官方公开价格的 8.2 折。Mini 480p 约 ¥0.20/秒，默认 5 秒无参考视频通常约 ¥0.9-1.0；最终以任务实际结算为准。

常见问题

注册后立刻用不了？

需要管理员审核。请先邮件联系 snamio131@gmail.com，并提供你的注册账号信息。

可以只配视频、不配图片吗？

可以。只填「视频」分组的 Key 并选好模型即可；其它分组可留空（显示为未配置 Key）。

为什么没有「新增渠道 / 改 Base URL」？

当前画布已预设直连地址与 4 个固定分组，避免填错地址或协议。只需按分组填 Key 并拉取模型。

Key 填错分组会怎样？

通常会鉴权失败、无可用模型或 401/403。请确认该 Key 对应中转站套餐，是否覆盖该分组推荐模型。

拉取模型成功但生成失败？

画布会自动使用已配置的 [直连域名]。请确认 Key 对应的套餐与模型分组正确；仍无法生成时请联系管理员。

画布和直接调 API 有什么关系？

画布是可视化入口；底层仍走中转站网关。需要程序化接入时，直接看本站各 API 文档即可。
