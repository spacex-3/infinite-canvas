gpt-image-2 图片生成

使用标准 OpenAI Images API 格式调用 gpt-image-2。适合直接对接兼容 OpenAI 的 SDK 与现有生图链路。

MODEL: gpt-image-2 GROUP: gpt-image-2 超分 FORMAT: OpenAI
POST [直连域名]/v1/images/generations
本页目录 直连域名 认证方式 错误提示 请求示例 请求参数 返回说明 接入注意

直连域名

图片接口使用 [直连域名]。将鼠标移到名称上可查看获取方式；接口路径保持以下文档所示。

认证方式

所有请求都需要在请求头中携带 API Key：

Authorization: Bearer sk-你的密钥

调用时请选择分组：gpt-image-2 超分。

错误提示（单独说明）

! 出现 400 / 内容拒绝时，通常不是网络问题 多半是提示词触发了上游内容安全策略（违规、版权、可识别真人等）。请修改 prompt 后重试，不要反复提交同一条内容。完整避坑请看 内容审查指南（视频 / 图片）。
  • 测试时请使用有意义的提示词，例如 cat、一只西瓜在跳舞；避免只用 test 这类无意义词。
  • 尽量避免：可识别真人正脸、未成年人、品牌 Logo、受保护 IP、色情暴力等敏感内容。
  • 若返回鉴权失败 / 401 / 403，优先检查 Key、分组是否选对（应为 gpt-image-2 超分）。
  • 若返回超时或 5xx，可稍后重试；内容审查类拒绝重试无效。

请求示例

curl

curl -s [直连域名]/v1/images/generations \
  -H "Authorization: Bearer sk-你的密钥" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "一只西瓜在跳舞，电影级光影，超高细节，写实质感",
    "n": 1,
    "size": "4096*4096"
  }'

请求参数

字段说明
model固定为 gpt-image-2
prompt必填，图片描述文本
n生成数量，示例为 1
size输出尺寸。示例高清尺寸：4096*4096

返回说明

接口遵循 OpenAI Images 风格返回。常见字段：

字段说明
created创建时间戳
data结果数组
data[].b64_jsonbase64 图片数据（若返回该字段）
data[].url图片链接（若返回该字段）

具体是返回 base64 还是 URL，取决于上游与当前渠道配置。客户端建议同时兼容两种字段。

返回示例（示意）

{
  "created": 1714200000,
  "data": [
    {
      "b64_json": "iVBORw0KGgoAAAANSUhEUgAA..."
    }
  ]
}

接入注意

  • 这是同步生图接口，请求会阻塞到生成完成再返回。
  • 高分辨率（如 4096*4096）耗时更长，请把客户端超时时间调大（建议 ≥ 180s）。
  • 分组请选择 gpt-image-2 超分，模型名必须是 gpt-image-2。
  • 若你还需要 Gemini 原生格式 / 4K banana 渠道，请看 Gemini 生图文档。
