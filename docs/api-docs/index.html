Base URL // Auth

图片与视频接口直连地址：

[直连域名]
  • 直连地址由当前画布预设；将鼠标移到 [直连域名] 可查看获取方式。
  • OpenAI 图片：POST /v1/images/generations（模型 gpt-image-2）
  • Gemini 图片：POST /v1beta/models/{model}:generateContent
  • 视频任务提交：POST /v1/videos
  • 视频任务查询：GET /v1/videos/{task_id}
  • 请求头：Authorization: Bearer api-key（Gemini 也可用 x-goog-api-key）
