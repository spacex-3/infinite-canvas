一、视频内容审查报错

如果你收到：

This request didn't pass content review (e.g. an identifiable real person, unsafe content, or protected IP). Retrying or switching accounts won't help. Try a non-photorealistic style, a non-identifiable or fictional subject (back/side/distant view), or rights-cleared content, then resubmit.

中文意思：请求没通过内容审查（可能涉及：可识别真人 / 不安全内容 / 受保护版权）。

关键：这是 Google 的确定性拒绝。

  • 重试没用
  • 换账号没用
  • 只能改提示词或换参考图

不要反复提交同一个请求，按下面的方法修改后再提交。

二、视频音频版权失败（单独说明）

如果视频生成失败信息里出现 PUBLIC_ERROR_AUDIO_FILTERED 或 AUDIO_GENERATION_FILTERED，通常表示音频版权 / 音频内容被过滤，不是普通网络抖动。

典型报错示例：

VEO video generation failed: status=MEDIA_GENERATION_STATUS_FAILED; code=3; message=PUBLIC_ERROR_AUDIO_FILTERED; failureReasons=AUDIO_GENERATION_FILTERED

结论：这是上游对音频轨道的确定性拒绝。

  • 重试同一条 prompt / 同一参考素材通常无效
  • 换账号通常无效
  • 需要改音频相关描述、去掉受保护音乐/歌词/歌手名，或换参考视频中的音频内容

高危音频写法

  • 点名真实歌手、乐队、专辑、完整歌词、热门 BGM / 广告歌
  • 要求“原曲 / 官方音轨 / 版权音乐完整还原”
  • 参考视频本身带有明显受保护的流行音乐、影视配乐
  • 要求模拟可识别的商标铃声、节目主题曲

建议改法

  • 改成“原创环境音 / 合成电子氛围 / 无歌词纯器乐氛围”
  • 不点名真实音乐 IP；用通用风格描述（如 soft ambient synth, cinematic score style）
  • 若参考视频有问题音轨，先换素材或明确要求“无版权音乐 / 无歌词”
  • 仅需画面时，可减少对具体歌曲的绑定描述

三、图片内容审查报错（gpt-image-2 / Gemini）

图片侧最常见的是 HTTP 400 或明确的内容拒绝。通常表示提示词 / 参考图触发了违规、版权或可识别真人等策略，属于确定性拒绝。

  • 重试或换账号通常无效，需要改 prompt 或换参考图
  • 测试时请用有意义的提示词（如 cat、一只西瓜在跳舞），不要只用 test
  • Gemini banana 与 gpt-image-2 超分分组都可能因真人、版权 IP、敏感内容被拒
  • 401 / 403 优先检查 Key 与分组；超时 / 5xx 可稍后重试

图片与视频的高危题材高度重合，请继续看下方「高危雷区」。图片额外注意：

  • 多参考图时，任意一张图都可能触发拒绝
  • 超写实真人正脸 + 名人长相尤其高危
  • 品牌 Logo、动漫游戏角色、影视截图同样高危

四、六大高危雷区（视频 / 图片通用）

1. 可识别的真人 / 名人，最常踩

  • 写实真人正脸、特写人像
  • 任何名人、明星、政治人物、网红的名字或长相
  • 上传真人照片当参考图（尤其正脸特写）
  • photorealistic（超写实）+ 真人 = 高危组合

2. 未成年人（零容忍）

  • 画面出现儿童 / 婴儿 / 青少年 / 学生
  • 哪怕本意无害，未成年人 + 任何危险或暧昧情境都会被拒

3. 性 / 裸露 / 暧昧

  • 裸露、性感、情色、内衣、暧昧亲密、床戏、诱惑等

4. 暴力 / 危险 / 血腥

  • 暴力、血腥、武器、打斗、战争、爆炸
  • 自杀、自残、事故、伤口、尸体、虐待
  • 危险动作 / 危险情境

5. 受保护版权（IP / 品牌）

  • 动漫游戏角色：皮卡丘、马里奥、奥特曼、米老鼠、艾莎、蜘蛛侠、哆啦A梦、火影等
  • 品牌商标：Nike、苹果、迪士尼、可口可乐、LV 等任何 logo
  • 影视形象：具名电影/电视剧角色、海报、截图

6. 其他敏感主题（容易被忽略）

  • 医疗病症：皮肤病、痤疮、湿疹、体味、伤口、疾病，这类真实案例容易踩过
  • 政治 / 宗教：领导人、宗教冲突、种族议题
  • 毒品 / 违法：毒品、吸毒等
  • 仇恨 / 歧视言论

五、安全改写对照表

高危写法安全改写
超写实真人 + 正脸特写改 3D动画 / 插画 / 卡通 风格；或使用侧面、背面、远景
上传真人照片生成不要使用正脸；改用远景/侧背面；或转为 动漫/卡通 风格
奥特曼大战怪兽改成“一个通用的巨人英雄”（不点名具体 IP）
情侣处理痤疮/皮肤病去掉病名，改成中性的“情侣约会”
小孩在火边玩耍改成“成年人”，或移除危险元素
含名人姓名改成“一位虚构的人物”

六、万能保险公式

不确定会不会被拒时，可以使用下面的组合：

非写实风格(non-photorealistic / 3D cartoon / illustration / anime)
+ 虚构、不具名的主体(fictional, non-identifiable subject)
+ 脸部不可识别(背面 / 侧面 / 远景)
+ 内容健康、无版权

七、快速自检清单（提交前过一遍）

  • 有没有真人/名人？转非写实风格或让脸部不可识别
  • 有没有儿童/青少年？移除或改为成年人
  • 有没有性/暴力/危险/血腥？删除相关描述
  • 有没有动漫角色/品牌/影视 IP？换成原创通用描述
  • 有没有病症/政治/毒品等敏感词？改为中性表达
  • 参考图是不是真人照片？换非写实图或远景
  • 视频是否点名真实歌曲 / 歌手 / 歌词 / 版权 BGM？改为原创环境音或通用风格
  • 图片多参考图时，是否逐张检查了敏感内容？

全部过关再提交，一次成功率最高。

遇到“temporarily unavailable / 暂时不可用”属于另一类（后端临时波动），可稍后重试；而“didn't pass content review / 没通过内容审查”是确定性拒绝，必须改内容。
