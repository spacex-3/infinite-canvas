默认视频模型 // 多模态参考

Seedance 2.0 / 2.5

支持文生视频、图片参考、视频参考和音频参考。默认推荐 Seedance 2.0 Mini，画布默认参数为 480p、5 秒、16:9、生成声音。

POST[直连域名]/v1/videos

模型与参数

Seedance 2.0 Minidoubao-seedance-2-0-mini-260615

默认首选，支持 480p / 720p。

Seedance 2.0 Fastdoubao-seedance-2-0-fast-260128

速度优先，支持 480p / 720p。

Seedance 2.5doubao-seedance-2-5-260628

常用比例：16:9、9:16、1:1、4:3、3:4、21:9、adaptive。2.0 系列通常支持 4-15 秒，2.5 最长 30 秒。

提交任务

所有请求使用本站 API Key：Authorization: Bearer api-key

curl -X POST [直连域名]/v1/videos \
  -H "Authorization: Bearer api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "doubao-seedance-2-0-mini-260615",
    "prompt": "清晨湖面上的游轮缓慢前行，镜头稳定，无文字，无水印。",
    "duration": 5,
    "metadata": {
      "resolution": "480p",
      "ratio": "16:9",
      "generate_audio": true
    }
  }'

提交成功会返回任务 id、status 和 progress。请保存任务 ID，不要在状态暂时未知时重复提交。

参考图片、视频和音频

参考素材放入 metadata.content，提示词中使用“图片1 / 视频1 / 音频1”说明用途。素材 URL 必须能被公网访问。

{
  "model": "doubao-seedance-2-0-mini-260615",
  "prompt": "保持图片1的主体外观，延续视频1的镜头运动，参考音频1的节奏。",
  "duration": 5,
  "metadata": {
    "resolution": "480p",
    "ratio": "16:9",
    "generate_audio": true,
    "content": [
      { "type": "image_url", "image_url": { "url": "https://your-cdn.com/ref.jpg" }, "role": "reference_image" },
      { "type": "video_url", "video_url": { "url": "https://your-cdn.com/ref.mp4" }, "role": "reference_video" },
      { "type": "audio_url", "audio_url": { "url": "https://your-cdn.com/ref.mp3" }, "role": "reference_audio" }
    ]
  }
}
!参考视频会增加实际用量参考时长越长、数量越多，用量通常越高；同时引用多个视频可能比单个同总时长视频更贵。参考音频不能单独使用，需同时提供图片或视频。

查询任务与下载

curl [直连域名]/v1/videos/task_id \
  -H "Authorization: Bearer api-key"
状态说明处理方式
queued排队中继续轮询
in_progress生成中读取 progress
completed已完成读取 content.video_url 或内容下载接口
failed生成失败查看 error.message

画布会在任务完成后先由服务器缓存视频，再下载到浏览器保存。刷新页面后可通过“重新下载”继续查询原任务，不会重新付费提交。

在无限画布中使用 Seedance

  1. 登录画布，在“配置与用户偏好”中给视频分组填写本站 API Key，并确认已选择 Seedance 模型。
  2. 把图片、视频或音频拖入画布；从素材节点拉线，选择“视频生成”。
  3. 在生成输入框输入 @，选择已连接素材。选中后显示为 @图片1、@视频1、@音频1。
  4. 明确素材用途，例如“保持 @图片1 的产品外观，延续 @视频1 的镜头运动”。
  5. 选择模型和参数。默认是 Mini、480p、5 秒、16:9、生成声音，然后点击生成。
  6. 生成完成后等待“服务器下载 / 正在下载 / 正在保存视频”，视频会自动回填为画布节点。

参考素材限制

  • 最多 9 张参考图、3 个参考视频、3 个参考音频。
  • 单个参考视频通常为 2-15 秒，全部参考视频总时长不超过 15 秒，单文件不超过 50MB。
  • 图片单文件不超过 30MB；音频单文件不超过 15MB。
  • 视频建议使用 MP4 / MOV、H.264 / H.265、24-60 FPS。
  • 包含未授权真人、隐私或受保护内容的素材可能被上游拒绝。
